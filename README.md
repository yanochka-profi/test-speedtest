# speedtest.py — замер скорости интернета

Консольный скрипт: делает указанное число **последовательных** запросов к URL,
полностью докачивает каждый ответ (стримом, **ничего не сохраняя на диск**),
и печатает среднее время запроса, суммарный объём и **среднюю скорость скачивания**.

## Требования

- Python 3.8+ (только стандартная библиотека, `pip install` не нужен).

## Запуск

```bash
python speedtest.py <URL>
```

Пример (тяжёлый файл — сетевой образ Debian):

```bash
python speedtest.py https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-13.7.0-amd64-netinst.iso -n 1
```

Вывод (реальный прогон):

```text
Цель: https://cdimage.debian.org/debian-cd/current/amd64/iso-cd/debian-13.7.0-amd64-netinst.iso
Запросов: 1, таймаут на запрос: 60 c
[1/1] 792.7 MB | 13.75 c | 461.2 Mbit/s

Среднее время запроса: 13.75 c
Всего скачано: 792.7 MB (792723456 байт)
Суммарное время: 13.75 c
Средняя скорость: 461.2 Mbit/s
```

### Опции

| Опция | По умолчанию | Значение |
|---|---|---|
| `-n, --requests` | **10** | число последовательных запросов |
| `--timeout` | 60 | секунд бездействия: столько ждём соединения и каждого нового блока данных (медленный, но льющийся поток не прервётся) |

Скрипт сам следует HTTP-редиректам (cdimage.debian.org отдаёт 302 на зеркало).
Если соединение оборвалось на середине файла — скрипт это заметит
(несовпадение Content-Length и посчитанных байт) и завершится с понятной
ошибкой, а не тихо занимит результат.

## Единицы измерения

- **Скорость — в битах в секунду** с SI-приставками: `bit/s`, `kbit/s`, `Mbit/s`,
  `Gbit/s`. Это те же единицы, в которых провайдеры обещают скорость:
  1 kbit/s = 1000 бит/с, 1 Mbit/s = 10⁶ бит/с.
- Средняя скорость = (суммарные байты × 8) / суммарное время всех запросов.
- **Объём — в мегабайтах по SI**: 1 МБ = 10⁶ байт (рядом печатаются точные байты).
- **Время — в секундах.**

## ⚠️ Про трафик

По умолчанию 10 запросов. Для Debian-нетинста (~793 МБ за штуку) это **~7.9 ГБ
трафика** за прогон. Для быстрой прикидки используйте `-n 1`.

## Тесты

```bash
python -m unittest -v tests.test_speedtest
```

Тесты не ходят в интернет: поднимают локальный HTTP-сервер на 127.0.0.1
(файл 3 МБ, редирект 302, «медленный» и «оборванный» ответы, 404) и проверяют
точный подсчёт байт, заголовки запроса, что на диск не пишется ни байта,
полный успех через CLI, коды выхода и форматирование единиц.
